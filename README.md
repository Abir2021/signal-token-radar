Signal / Radar ranks protocols with no token recorded from a sealed TVL, growth and tenure snapshot. It separates live-token references, explains the model and offers an offline dashboard with filters, protocol detail and cautious participation plans.

## Run it

```sh
node main.ts --input /path/to/snapshot.json --output ./output
```
